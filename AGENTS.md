# LIVSOLV Shared Agent Protocol

This repository is the source of truth for LIVSOLV work across ChatGPT, Claude, GitHub, and the user's Obsidian vault.

## Start every substantial session

1. Read `AGENTS.md`.
2. Read `PROJECT_STATUS.md`.
3. Read `DECISIONS.md`.
4. Read the relevant product or page specification.
5. Verify external state before saying anything is live, sent, posted, scheduled, approved, connected, or complete.

## End every substantial session

1. Update `PROJECT_STATUS.md` when priorities, blockers, completed work, or the next action changed.
2. Append to `DECISIONS.md` only when a durable decision changed.
3. Update the relevant specification when deliverables or acceptance criteria changed.
4. Keep updates concise. Use dates in YYYY-MM-DD format and identify unverified claims.
5. Commit with a plain-language message that states the outcome.

## Working rules

- Do not create a second source of truth in chat, Obsidian, or another tool. Those systems may display or edit these repository files.
- Never store passwords, government IDs, private account numbers, medical records, or other sensitive personal data in this public repository.
- Preserve user work and inspect before overwriting.
- Use actual camera photography with a traceable source for public-facing LIVSOLV imagery. Do not use AI-generated or AI-looking photography unless the user explicitly approves it.
- LIVSOLV content must be practical, calm, specific, and clear about limitations.
- Report one immediate next action, not an unranked task dump.
